## 一、项目目标
- 构建端到端平台：采集/清洗黄金相关数据，进行趋势分析与价格预测
- 提供可视化仪表盘与可操作洞察，支持实时监控与风险提示
- 面向分析师与交易员，提升决策效率与稳健性

## 二、核心功能（已实现）
- **用户认证与安全**：支持用户注册、登录、修改密码，集成图形验证码与密码强度校验，保障账户安全。
- **实时与历史数据接入**：支持 K 线（1m/1h/1d）数据的自动采集与清洗。
- **数据清洗与特征工程**：自动处理时区、复权与格式化，确保数据一致性。
- **技术指标分析**：支持 MA、MACD、RSI 等常用技术指标的实时计算与可视化。
- **预测模型**：集成 Prophet/ARIMA 等模型，提供未来 1-30 天的价格预测（含置信区间）。
- **实时监控与告警**：分钟级价格监控，支持自定义阈值告警与系统默认告警（涨跌幅、整数关口）。
- **可视化仪表盘**：全中文界面，集成行情、预测、告警与系统状态的一站式视图。

## 三、功能模块详情

### 1. 用户认证 (User Authentication)
- **登录/注册**：
  - 支持用户名/密码登录与注册。
  - **图形验证码**：登录、注册、修改密码均需验证图形验证码，防止自动化攻击。
  - **密码安全**：强制要求密码长度至少8位，且包含字母和数字。
- **账户管理**：
  - 支持用户修改登录密码。
  - 登录后自动显示当前用户名。

### 2. 仪表盘 (Dashboard)
- **实时行情卡片**：
  - 显示最新黄金价格（人民币元/克）。
  - 显示当日涨跌幅（红涨绿跌，符合国内习惯）。
- **预测概览卡片**：
  - 显示次日预测价格。
- **活跃告警卡片**：
  - 显示当前触发且未处理的告警数量。
- **历史价格走势图**：
  - 支持 **1天**（分钟级数据）、**1月**（小时级数据）、**3月/1年**（日线数据）切换。
  - **自动刷新**：图表每 60 秒自动更新，保持数据实时性。
- **数据采集状态**：
  - 实时展示后台任务状态（实时监控、小时线采集、日线采集）。
  - 显示上次执行时间、插入条数及错误信息。
- **活跃告警列表**：
  - 展示当前生效的告警规则。
  - 支持快速新增与删除告警。

### 3. 市场数据 (Market Data)
- **数据表格**：
  - 展示时间、开盘价、最高价、最低价、收盘价、成交量。
  - **排序优化**：按时间**倒序排列**（最新数据在最前）。
  - **多维度筛选**：
    - 品种：XAUUSD。
    - 周期：**分钟线 (1m)**、小时线 (1h)、日线 (1d)。
    - 区间：最近一月、最近三月、最近一年。
  - **数据导出**：支持将筛选后的数据导出为 CSV 文件。

### 4. 分析与预测 (Analysis & Forecast)
- **技术指标分析**：
  - 支持 RSI、MACD、MA 指标切换。
  - **指标解读**：提供每个指标的中文含义与用法说明（如 RSI 超买超卖）。
  - 交互式图表展示指标历史走势。
- **价格预测**：
  - 展示历史价格与未来预测曲线（含上下界置信区间）。
  - **预测结论**：根据模型数据自动生成文字解读（看涨/看跌/震荡），并显示具体涨跌幅。
- **交易品种说明**：
  - 提供 XAUUSD 等品种的基础知识科普。
- **自动刷新**：
  - 分析图表与数据每 60 秒自动更新。

### 5. 监控与告警 (Alerts)
- **自定义告警**：
  - 用户可创建“价格高于”或“价格低于”指定阈值的规则。
- **系统默认告警**：
  - 系统启动时若无规则，自动初始化默认策略：
    - 价格上涨 > 1%
    - 价格下跌 > 1%
    - 突破整数关口（如 2600 -> 2700）
- **实时触发**：
  - 后端调度器每 5 分钟检查一次最新价格，满足条件即触发。

## 四、系统架构

### 1. 前端 (Frontend)
- **框架**：Vue 3 + TypeScript + Vite
- **UI 组件库**：Element Plus
- **图表库**：ECharts 5
- **特性**：
  - 全面响应式布局。
  - 全中文界面与提示。
  - 自动轮询机制（Auto-polling）确保数据实时性。
  - 模块化组件设计（Chart, Alert, Status）。

### 2. 后端 (Backend)
- **框架**：FastAPI (Python 3.10+)
- **数据库**：MySQL 8.0 (SQLAlchemy ORM)
- **调度器**：APScheduler (BackgroundScheduler)
- **核心模块**：
  - `AuthController`: 处理用户注册、登录、修改密码及验证码生成。
  - `MarketController`: 处理行情查询与导出。
  - `ForecastController`: 处理预测请求与逻辑封装。
  - `AlertService`: 告警规则管理与实时检测。
  - `Scheduler`: 负责 1m/1h/1d 数据的定时采集与清洗。
  - `CaptchaService`: 负责图形验证码的生成与验证。

### 3. 开发部署
- **代码仓库**：https://github.com/bzgz-tech/GPAFP
- **网络配置**：由于网络环境限制，Git 推送需指定代理：
  `git -c http.proxy=http://127.0.0.1:7890 -c https.proxy=http://127.0.0.1:7890 push`

## 五、非功能性特性
- **安全性**：
  - 用户密码经过哈希加密存储。
  - 关键操作（登录/注册/改密）强制图形验证码校验。
  - API 接口采用 JWT 令牌认证。
- **性能**：仪表盘图表加载延迟 < 500ms，支持分钟级数据渲染。
- **可靠性**：后台任务具备错误捕获与状态记录机制，失败不影响主服务。
- **易用性**：关键指标与预测结果均提供文字解读，降低用户认知门槛。
- **国际化**：已完全本地化为中文环境（时间格式、货币单位、提示语）。
